# Mendeley Bibliography Guide
## Topic: Clickbait — Effectiveness, Ethics, and Credibility (Media Studies MA)

This guide helps you evaluate, select, and organise ~20 academic sources in Mendeley
for a media-studies master's bibliography on **clickbait, journalistic credibility, ethics,
and audience engagement**.

---

## 1. Source-Selection Criteria

Use these five criteria to decide whether a source belongs in your list:

| # | Criterion | Why it matters |
|---|-----------|----------------|
| 1 | **Discipline fit** | Prefer journalism / communication / media-studies journals over pure computer-science / NLP / IEEE venues. One or two technical sources are fine as interdisciplinary evidence. |
| 2 | **Peer-reviewed** | Journal articles and edited book chapters from established publishers (Taylor & Francis, Elsevier, Sage, Springer, APA) carry the most academic weight. |
| 3 | **Topic relevance** | The source should address at least one of: clickbait definition/typology, journalistic credibility/trust, audience engagement, headline ethics, or content-analysis methodology. |
| 4 | **Recency** | Prefer sources from 2015 onward; older "classics" (e.g., Esser 1999 on tabloidisation) are acceptable as foundational references. |
| 5 | **No thematic duplication** | Before adding, check which existing sources already cover the same angle (see Section 4 below). |

## 3. Organising ~20 Sources in Mendeley

### 3.1 Recommended folder / collection structure

Create one top-level folder and sub-folders (Mendeley → *New Folder*):

```
MA Clickbait Bibliography/
├── 1_Definitions & Typology
├── 2_Ethics & Systemic Challenges
├── 3_Credibility & Trust Effects
├── 4_Audience Engagement & Virality
├── 5_Platform & Algorithmic Context
├── 6_Methodology (Content Analysis)
└── 7_Interdisciplinary (NLP / Technical — max 2)
```

### 3.2 Tagging convention

Add tags to every record so you can filter across folders:

| Tag | Use when… |
|-----|-----------|
| `core` | Source you will cite in ≥ 2 chapters |
| `definition` | Provides a working definition or typology of clickbait |
| `ethics` | Discusses journalistic ethics or normative evaluation |
| `credibility` | Empirically measures trust/quality perceptions |
| `engagement` | Covers clicks, shares, virality, or A/B testing |
| `methodology` | Explains content analysis or research design |
| `classic` | Published before 2010; foundational theory |
| `open-access` | Free full text available |

### 3.3 Metadata checklist (per record)

For each Mendeley entry verify:
- [ ] **Authors** — correct surnames and initials, no "Running head…" text.
- [ ] **Year** — correct publication year (not *n.d.*).
- [ ] **Title** — full article title, sentence-case.
- [ ] **Journal / Book** — full journal name, not abbreviation.
- [ ] **Volume / Issue / Pages** — fill in from the publisher page.
- [ ] **DOI** — paste the DOI string; Mendeley can auto-fill other fields from it (*Tools → Add entry manually → search by identifier*).

> **Fixing a broken record** (e.g., Ecker et al. with *n.d.* and "cogsciwa.com"):
> 1. Delete the broken entry.
> 2. Open Google Scholar → search the article title → click **Cite** → **BibTeX**.
> 3. Save the `.bib` file, then in Mendeley: *File → Import → BibTeX*.
> 4. Confirm year = **2014**, journal = *Journal of Experimental Psychology: Applied*.

## 5. Quick Mendeley Tips

- **Import from DOI**: drag a DOI string onto the Mendeley desktop window, or use *Add entry manually → Search by identifier*.
- **Duplicate detection**: *Edit → Find Duplicates* before finalising the list.
- **Citation style**: for media-studies theses APA 7th is common; set it in *View → Citation Style*.
- **Group library**: if you share with a supervisor, invite them via *Tools → Invite to group*.
- **Annotate PDFs**: open any attached PDF in Mendeley, highlight passages, and use notes — highlights are searchable later.
